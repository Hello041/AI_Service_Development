# 01: 운영자 로그인·로그아웃

**What to build:** 운영자가 `/admin`에서 공유 비밀번호로 로그인하면 (아직 비어 있는) 운영자 대시보드를 보고, 로그아웃할 수 있다. 로그인은 1일간 유지된다. 로그인하지 않은 채 운영자 화면에 접근하면 로그인 화면으로 보내진다. 틀린 비밀번호는 약 1초 지연 후 실패 안내를 받는다. 이후 모든 운영자 기능이 이 인증 위에 올라간다.

스펙: `.scratch/voting-app/spec.md` (운영자 — 로그인, 운영자 인증 모듈). 용어는 `CONTEXT.md`를 따른다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Vitest가 설정되어 테스트 스크립트로 실행된다
- [ ] 운영자 인증 모듈(DB 미사용 순수 모듈): 비밀번호 확인(상수 시간 비교), 1일 만료 세션 토큰 발급, 서명·만료 검증
- [ ] 비밀번호는 `ADMIN_PASSWORD`, 서명 키는 `SESSION_SECRET` 환경변수에서 읽는다
- [ ] `/admin` 로그인 화면(한국어, 모바일 기준)에서 올바른 비밀번호로 로그인하면 대시보드로 이동한다
- [ ] 세션은 httpOnly 서명 쿠키로 1일 유지되고, 로그아웃 버튼은 쿠키를 삭제한다
- [ ] 틀린 비밀번호는 약 1초 지연 후 실패 안내를 보여준다
- [ ] 세션 없이(또는 만료·위조된 세션으로) 운영자 화면에 접근하면 로그인 화면으로 보내진다
- [ ] 인증 모듈 테스트: 올바른/틀린 비밀번호, 유효 토큰 통과, 위조 서명 거부, 1일 경과 토큰 거부(시각 주입)
- [ ] 참여자 화면에는 운영자 메뉴가 드러나지 않는다
