# 05: 투표 삭제

**What to build:** 운영자가 대시보드에서 투표를 삭제한다. 삭제 전 "표 N개도 함께 삭제됩니다" 확인 창을 거치며, 표가 있는 투표도 삭제할 수 있다. 삭제된 투표는 선택지·표와 함께 완전히 사라져 목록·링크·결과 어디에도 나오지 않는다.

스펙: `.scratch/voting-app/spec.md`.

**Blocked by:** 03 (표 던지기와 결과 보기)

**Status:** ready-for-agent

- [ ] 운영자만 삭제할 수 있다(세션 검증)
- [ ] 확인 창에 해당 투표의 표 수가 표시된다
- [ ] 하드 삭제: 투표와 그 선택지·표가 함께 삭제된다
- [ ] 삭제된 투표 링크를 열면 "없는 투표" 안내
- [ ] 화면을 열어둔 사이 삭제된 투표에 표를 던지면 "없는 투표" 안내
- [ ] 투표 모듈 테스트: 삭제 후 목록·참여자 조회·운영자 조회에서 사라짐, 삭제된 투표에 표 거부, 다른 투표의 표는 영향 없음
