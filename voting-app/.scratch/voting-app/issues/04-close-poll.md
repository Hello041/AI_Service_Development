# 04: 투표 마감

**What to build:** 운영자가 대시보드에서 진행 중인 투표를 마감한다(되돌릴 수 없음). 마감된 투표는 더 이상 표를 받지 않고, 투표 화면에는 폼 대신 "마감됨" 안내와 결과가 보이며, 표를 던지지 않은 참여자도 결과를 볼 수 있다. 첫 화면 목록은 진행 중인 투표를 위에, 마감된 투표를 아래에 "마감" 표시와 함께 각각 최신순으로 보여준다.

스펙: `.scratch/voting-app/spec.md`. 용어 "마감"은 `CONTEXT.md`를 따른다.

**Blocked by:** 03 (표 던지기와 결과 보기)

**Status:** done

- [x] 이미 마감된 투표를 다시 마감해도 변화 없음

- [x] 결과 공개 조건 확장: 표를 던졌거나 투표가 마감되면 참여자에게 결과 공개
- [x] 첫 화면 목록: 진행 중 먼저·마감 나중, 각각 최신순, 마감 표시
