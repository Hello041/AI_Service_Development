# 01: 투표 모듈에 현재 시각 주입 (구조 정리)

**What to build:** 이후 마감 시각 기능을 쉽게 넣기 위한 구조 정리. 투표 모듈이 현재 시각을 돌려주는 함수를 주입받고, "마감됨" 판단을 모듈 안 한 곳으로 모은다. 사용자에게 보이는 동작은 바뀌지 않는다.

스펙: `.scratch/deadline-graph-voter-name/spec.md` (투표 모듈 변경, 마감 판단). ADR-0002.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 투표 모듈이 SQL 실행 함수와 함께 현재 시각 함수를 주입받는다(운영: 실제 시계, 테스트: 고정 시각)
- [x] 마감 판단 SQL이 한 곳에 모이고, DB의 현재 시각이 아니라 주입된 시각을 파라미터로 쓴다
- [x] 기존 테스트가 모두 그대로 통과한다
- [x] (추가) 같은 시각에 만든 투표의 목록 순서가 흔들리던 불안정한 테스트를 만든 순서 번호로 고정
