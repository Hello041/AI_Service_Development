# 06: 기명 투표

**What to build:** 운영자가 투표를 만들 때 기명·익명을 고른다(기본 기명, 만든 뒤 변경 불가). 기명 투표에서는 표를 던진 시점의 참여자 이름이 표에 남고, 운영자 투표 화면의 그래프 아래에 선택지별로 누가 골랐는지 표를 던진 순서대로 나온다. 참여자 화면에는 기명·익명 안내가 나오고 다른 참여자 이름은 보이지 않는다. 기존 투표는 익명으로 동작한다.

스펙: `.scratch/deadline-graph-voter-name/spec.md` (기명 투표). ADR-0003, ADR-0001.

**Blocked by:** 05 (참여자 이름 입력과 헤더 표시)

**Status:** ready-for-agent

- [ ] `schema.sql`: 투표에 기명 여부(DB 기본값 익명), 표에 참여자 이름 컬럼 추가(기존 데이터 보존)
- [ ] 투표 만들기에 기명 여부, 만들기 화면 체크박스(기본 켜짐)와 설명
- [ ] 표 던지기: 기명이면 이름 필수·검증 후 저장(거부 사유 구분), 익명이면 이름 저장 안 함. 서버 액션은 쿠키의 현재 이름을 넘기고, 이름이 없으면 이름 입력 화면으로
- [ ] 운영자 조회: 기명이면 선택지별 이름 목록(던진 순서, 중복 이름 허용), 익명이면 없음. 참여자 조회에는 이름 없음
- [ ] 참여자 투표 화면 기명·익명 안내, 대시보드·운영자 투표 화면에 기명/익명 표시
- [ ] 투표 모듈 테스트: 이름 없이 거부, 이름 규칙 위반 거부, 운영자 조회 이름 목록과 순서, 같은 이름 허용, 참여자 조회에 이름 없음, 익명 투표는 이름 목록 없음, 기명 여부를 정하지 않은 투표는 익명
