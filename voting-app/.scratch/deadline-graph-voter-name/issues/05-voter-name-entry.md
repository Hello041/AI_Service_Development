# 05: 참여자 이름 입력과 헤더 표시

**What to build:** 참여자가 참여자 화면(목록, 투표 화면)에 처음 들어오면 이름 입력 화면이 먼저 나오고, 이름을 적으면 원래 가려던 화면으로 돌아간다. 이름은 브라우저에 기억되고, 화면 오른쪽 위 헤더에 "OOO 님 · 변경"으로 항상 보인다. 운영자 화면에는 이름 입력 화면이 끼어들지 않는다.

스펙: `.scratch/deadline-graph-voter-name/spec.md` (참여자 이름). ADR-0003.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 참여자 이름 검증 순수 함수: 앞뒤 공백 제거 후 1~20자(코드 포인트)
- [ ] 이름은 참여자 식별자와 별도의 오래 유지되는 쿠키에 서버 액션으로 저장·변경
- [ ] 참여자 화면에 이름이 없으면 이름 입력 화면으로 이동, 저장 후 원래 주소로 복귀(앱 내부 경로만 허용)
- [ ] `/admin` 아래와 이름 입력 화면 자체는 검사하지 않음
- [ ] 헤더 오른쪽 위 "운영자 로그인" 왼쪽에 "OOO 님 · 변경", "변경"은 현재 이름을 채운 입력 화면으로
- [ ] 휴대폰에서 헤더가 깨지지 않음
- [ ] 이름 검증 테스트: 빈 값·공백만·20자·21자·앞뒤 공백 제거
