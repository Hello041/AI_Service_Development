# 03: 마감 시각을 정해 투표 만들기와 자동 마감

**What to build:** 운영자가 투표를 만들 때 마감 시각을 넣거나(기본값: 지금부터 24시간 뒤) "마감 시각 없음"을 고른다. 마감 시각이 지나면 투표는 자동으로 마감되어 표를 받지 않고 누구나 결과를 본다. 참여자·운영자 투표 화면과 목록에 "9월 30일 (화) 18:00 마감 · 5시간 남음"이 보이고, 24시간 이내면 강조된다. 진행 중인 투표는 마감이 가까운 순으로 목록 위에 온다.

스펙: `.scratch/deadline-graph-voter-name/spec.md`. ADR-0002. 용어 "마감 시각"은 `CONTEXT.md`.

**Blocked by:** 01 (투표 모듈에 현재 시각 주입)

**Status:** ready-for-agent

- [ ] `schema.sql`: 투표에 마감 시각 컬럼 추가(기존 데이터 보존, 여러 번 적용 안전)
- [ ] 시각 표시 모듈(순수 함수, 한국 시간 기준): 입력칸 값 ↔ 시각, 24시간 뒤 기본값, 마감 문구, 남은 시간 문구(분·시간·일), 24시간 이내 판단
- [ ] 투표 만들기: 마감 시각(없음 허용), 현재 이하 시각 거부(구분 가능한 오류)
- [ ] 마감 판단: 운영자 마감 또는 마감 시각 도달. 표 거부·결과 공개·목록·화면이 모두 같은 판단
- [ ] 목록 정렬: 마감 시각 가까운 순 → 마감 시각 없는 진행 중 최신순 → 마감됨 최신순
- [ ] 만들기 화면: 마감 시각 입력칸(24시간 뒤 미리 채움) + "마감 시각 없음"
- [ ] 참여자·운영자 투표 화면과 목록에 마감 시각·남은 시간, 24시간 이내 강조
- [ ] 투표 모듈 테스트: 마감 시각 1분 전 허용·지나면 거부, 지나면 미참여자 결과 공개, 운영자 마감이 먼저여도 마감, 과거·현재 시각 거부, 없음 허용, 목록 정렬
- [ ] 시각 표시 모듈 테스트: 왕복 변환, 자정·날짜 경계, 문구, 남은 시간 경계, 24시간 경계, 실행 환경 시간대와 무관
