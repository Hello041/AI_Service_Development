# 마감 시각, 결과 그래프, 참여자 이름과 기명 투표

Status: ready-for-agent

## Problem Statement

동아리 회장이 두 번째로 요청했다. "투표를 계속 열어두니까 사람들이 마감 없이 늘어져서 참여를 안 해요. 마감 시간을 정할 수 있게 해주시고, 결과도 숫자 말고 그래프로 보고 싶어요." 지금 투표는 운영자가 직접 마감 버튼을 누를 때까지 열려 있어 참여자가 서두를 이유가 없고, 결과 화면은 얇은 막대와 숫자 위주라 한눈에 들어오지 않는다. 또 누가 참여했는지 알 수 없어 운영자가 참여를 독려하기 어렵다. 과제 조건도 같은 세 가지를 요구한다: (1) 투표 마감 시간 설정 (2) 투표 결과를 그래프로 표시 (3) 투표 앱 화면에 자기 이름 적기.

## Solution

- **마감 시각**: 운영자가 투표를 만들 때 마감 시각을 정할 수 있고(기본값: 지금부터 24시간 뒤, 비워 둘 수도 있음), 진행 중에는 바꾸거나 없앨 수 있다. 마감 시각이 지나면 투표는 자동으로 마감된다. 참여자는 투표 화면과 목록에서 "9월 30일 (화) 18:00 마감 · 5시간 남음"을 보고, 마감이 가까운 투표가 목록 위에 온다.
- **결과 그래프**: 결과는 두꺼운 가로 막대 그래프로 보여주고, 1위 선택지를 강조한다.
- **참여자 이름과 기명 투표**: 참여자는 앱에 들어올 때 이름을 적고, 그 이름이 화면 오른쪽 위에 계속 보인다. 운영자는 투표를 기명 또는 익명으로 만든다. 기명 투표에서는 표를 던진 시점의 이름이 표에 남고, 누가 무엇을 골랐는지는 운영자만 본다.

## User Stories

### 참여자 — 이름

1. As a 참여자, I want 앱에 처음 들어올 때 이름을 적는 화면을 보기, so that 내가 누구인지 밝히고 참여할 수 있다
2. As a 참여자, I want 공유 링크로 들어와 이름을 적으면 원래 가려던 투표 화면으로 바로 이어지기, so that 링크를 다시 열지 않아도 된다
3. As a 참여자, I want 이름이 비었거나 20자를 넘으면 안내를 받기, so that 올바른 이름을 적을 수 있다
4. As a 참여자, I want 이름 앞뒤 공백이 자동으로 지워지기, so that 실수로 넣은 공백이 이름에 남지 않는다
5. As a 참여자, I want 한 번 적은 이름을 이 브라우저가 기억하기, so that 들어올 때마다 다시 적지 않아도 된다
6. As a 참여자, I want 화면 오른쪽 위에서 "OOO 님"으로 내 이름을 항상 보기, so that 어떤 이름으로 참여 중인지 알 수 있다
7. As a 참여자, I want 이름 옆 "변경" 버튼으로 언제든 이름을 바꾸기, so that 잘못 적었거나 다른 이름을 쓰고 싶을 때 고칠 수 있다
8. As a 참여자, I want 이름을 바꿔도 이미 던진 표의 이름은 그대로이기, so that 내 과거 표가 뒤섞이지 않는다
9. As a 참여자, I want 휴대폰에서도 이름 표시가 헤더에서 잘리지 않기, so that 작은 화면에서도 확인할 수 있다

### 참여자 — 기명·익명

10. As a 참여자, I want 투표 화면에서 기명 투표인지 익명 투표인지 표시를 보기, so that 내 이름이 남는지 알고 표를 던질 수 있다
11. As a 참여자, I want 기명 투표에서는 "OOO 이름으로 표가 남습니다. 누가 무엇을 골랐는지는 운영자만 봅니다" 같은 안내를 보기, so that 내 선택이 누구에게 보이는지 안다
12. As a 참여자, I want 익명 투표에서는 내 이름이 표에 남지 않기, so that 민감한 주제에도 부담 없이 투표할 수 있다
13. As a 참여자, I want 결과 화면에는 다른 참여자의 이름이 보이지 않기, so that 다른 사람 눈치를 보지 않고 투표할 수 있다

### 참여자 — 마감 시각

14. As a 참여자, I want 투표 화면에서 마감 시각과 남은 시간을 보기, so that 언제까지 참여해야 하는지 안다
15. As a 참여자, I want 목록의 각 투표에서도 마감 시각과 남은 시간을 보기, so that 급한 투표를 먼저 찾을 수 있다
16. As a 참여자, I want 남은 시간이 24시간 이내면 눈에 띄게 강조되기, so that 곧 마감되는 투표를 놓치지 않는다
17. As a 참여자, I want 진행 중인 투표가 마감이 가까운 순으로 목록 위에 오기, so that 서둘러야 할 투표부터 참여할 수 있다
18. As a 참여자, I want 마감 시각이 없는 진행 중 투표는 마감 시각이 있는 투표 뒤에 최신순으로 보이기, so that 목록 순서가 예측 가능하다
19. As a 참여자, I want 마감 시각이 지난 투표에서는 투표 폼 대신 "마감된 투표입니다"와 결과를 보기, so that 더 이상 참여할 수 없음을 알고 결과는 확인할 수 있다
20. As a 참여자, I want 화면을 열어둔 사이 마감 시각이 지난 뒤 표를 던지면 마감 안내를 받기, so that 표가 반영됐다고 착각하지 않는다
21. As a 참여자, I want 모든 시각이 한국 시간으로 보이기, so that 서버 위치와 상관없이 시각을 바로 이해할 수 있다

### 참여자 — 결과 그래프

22. As a 참여자, I want 결과를 두꺼운 가로 막대 그래프로 보기, so that 숫자를 읽지 않아도 결과를 한눈에 비교할 수 있다
23. As a 참여자, I want 막대에 선택지 이름과 비율(%)이 표시되기, so that 어떤 막대가 어떤 선택지인지 바로 안다
24. As a 참여자, I want 표 수가 작게 함께 표시되기, so that 필요하면 정확한 숫자도 확인할 수 있다
25. As a 참여자, I want 1위 선택지가 색으로 강조되기, so that 가장 많이 받은 선택지를 바로 알 수 있다
26. As a 참여자, I want 1위가 동점이면 동점인 선택지가 모두 강조되기, so that 공동 1위를 공정하게 볼 수 있다
27. As a 참여자, I want 표가 하나도 없으면 아무 선택지도 강조되지 않기, so that 1위가 있는 것처럼 오해하지 않는다
28. As a 참여자, I want 내가 고른 선택지가 그래프에서 표시되기, so that 내 선택을 확인할 수 있다
29. As a 참여자, I want 선택지 이름이 길어도 휴대폰에서 그래프가 깨지지 않기, so that 어떤 기기로든 결과를 볼 수 있다
30. As a 참여자, I want 그래프 선택지가 만든 순서대로 유지되기, so that 표 수에 따라 순서가 뒤바뀌어 헷갈리지 않는다

### 운영자 — 마감 시각

31. As a 운영자, I want 투표 만들기 화면에서 마감 시각을 날짜·시각(분 단위)으로 입력하기, so that 참여 기한을 정할 수 있다
32. As a 운영자, I want 마감 시각 입력칸에 "지금부터 24시간 뒤"가 미리 채워져 있기, so that 대부분의 투표에 손쉽게 기한을 붙일 수 있다
33. As a 운영자, I want "마감 시각 없음"을 골라 기한 없는 투표를 만들기, so that 상시로 열어 둘 투표도 만들 수 있다
34. As a 운영자, I want 과거 시각을 마감 시각으로 넣으면 안내를 받기, so that 만들자마자 마감되는 투표가 생기지 않는다
35. As a 운영자, I want 진행 중인 투표의 마감 시각을 운영자 투표 화면에서 바꾸기, so that 참여가 적을 때 기한을 연장하거나 앞당길 수 있다

## Implementation Decisions

### 용어

- 코드와 UI 모두 `CONTEXT.md`의 용어를 따른다. 이번에 새로 쓰는 용어: 마감 시각(Deadline), 참여자 이름(Voter Name), 기명 투표(Named Poll), 익명 투표(Anonymous Poll). 마감(Close)은 "운영자가 직접 마감하거나 마감 시각이 지나 표를 받지 않게 되는 것"으로 넓어졌다.

### 마감 판단 (ADR-0002)

- 투표가 마감되었는지는 예약 작업 없이 읽을 때마다 "운영자가 마감했음 또는 마감 시각이 현재 시각 이하"로 판단한다. 표 던지기 거부, 결과 공개 조건, 목록 정렬, 화면의 마감 표시가 모두 같은 판단을 쓴다.
- 이 판단은 투표 모듈 한 곳에서만 한다. 운영자 마감 기록만 보고 마감 여부를 결정하는 코드를 따로 두지 않는다.
- 운영자 마감과 마감 시각 도달을 화면에서 구분하지 않는다. 둘 다 "마감"으로 보인다.

### 투표 모듈 변경

- 투표 모듈은 SQL 실행 함수에 더해 **현재 시각을 돌려주는 함수를 주입받는다.** 운영에서는 실제 시계, 테스트에서는 고정 시각을 넣는다. 마감 판단과 과거 시각 검증은 DB의 현재 시각이 아니라 주입된 현재 시각을 SQL 파라미터로 넘겨 계산한다.
- 투표 만들기: 입력에 마감 시각(없을 수 있음)과 기명 여부가 추가된다. 마감 시각이 현재 시각 이하이면 거부한다(구분 가능한 오류).
- 마감 시각 설정: 새 기능. 투표 id와 새 마감 시각(없애기는 "없음")을 받는다. 거부 사유를 구분한다: 없는 투표 / 이미 마감된 투표 / 과거 시각.
- 표 던지기: 기명 투표에서는 참여자 이름이 필요하고, 표에 그 이름을 저장한다. 익명 투표에서는 이름을 받더라도 저장하지 않는다. 기명 투표인데 이름이 없거나 규칙에 맞지 않으면 거부한다(구분 가능한 오류). 마감 판단은 위 규칙을 따른다.
- 조회(참여자·운영자·목록): 투표 정보에 마감 시각, 기명 여부, 마감 여부(위 규칙으로 계산)가 포함된다.
- 결과: 선택지마다 1위 여부가 포함된다. 표 수가 최댓값인 모든 선택지가 1위이고, 총 표가 0이면 1위가 없다.
- 운영자 조회: 기명 투표이면 선택지별로 표를 던진 순서대로 참여자 이름 목록을 포함한다. 익명 투표이면 포함하지 않는다. 참여자 조회에는 어떤 경우에도 다른 참여자의 이름이 포함되지 않는다.
- 목록 정렬: 진행 중 투표 중 마감 시각이 있는 것을 마감 시각이 가까운 순, 그다음 마감 시각이 없는 진행 중 투표를 최신순, 그다음 마감된 투표를 최신순.
- 기명 여부는 만든 뒤 바꾸는 기능을 두지 않는다.

### 시각 표시 모듈 (새, 순수 함수)

- 모든 사람이 보는 시각은 한국 시간(Asia/Seoul) 기준이다. 서버 위치와 무관해야 한다.
- 제공 기능: 날짜·시각 입력칸 값(분 단위, 한국 시간)을 시각으로 바꾸기, 시각을 입력칸 값으로 바꾸기, 현재 시각 기준 "24시간 뒤" 기본값 만들기, "9월 30일 (화) 18:00 마감" 형식의 문구 만들기, "5시간 남음"·"25분 남음"·"2일 남음" 형식의 남은 시간 문구 만들기, 24시간 이내 여부 판단.
- 현재 시각은 인자로 받는다(테스트 가능).

### 참여자 이름 (ADR-0003)

- 참여자 이름 검증은 작은 순수 함수로 둔다: 앞뒤 공백 제거 후 1~20자(코드 포인트 기준).
- 참여자 이름은 참여자 식별자와 별도의 오래 유지되는 쿠키에 저장한다. 서버 액션에서 저장·변경한다.
- 이름 입력 화면: 참여자 화면(첫 화면 목록, 투표 화면)에 이름 쿠키가 없으면 이름 입력 화면으로 보낸다. 원래 가려던 주소를 함께 넘기고, 이름을 저장하면 그 주소로 돌아간다. 돌아갈 주소는 앱 내부 경로만 허용한다(외부 주소로의 리다이렉트 방지).
- 운영자 화면(`/admin` 아래)과 이름 입력 화면 자체에는 이 검사를 적용하지 않는다.
- 헤더 오른쪽 위, "운영자 로그인" 버튼 왼쪽에 "OOO 님 · 변경"을 표시한다. 이름이 없으면 표시하지 않는다. "변경"은 이름 입력 화면으로 가며 현재 이름을 미리 채운다.
- 중복 방지는 ADR-0001대로 참여자 식별자 쿠키로만 한다. 이름으로 중복을 막지 않는다.
- 표를 던질 때 서버 액션이 쿠키의 현재 이름을 읽어 투표 모듈에 넘긴다. 이름이 없는 채로 기명 투표에 표를 던지면 이름 입력 화면으로 보낸다.

### 결과 그래프

- 차트 라이브러리 없이 CSS로 그린다. 선택지마다 두꺼운 가로 막대 하나, 막대 위(또는 안)에 선택지 이름과 비율(%), 옆에 작게 표 수. 1위 선택지는 강조 색. 내 선택 표시는 유지. 선택지 순서는 만든 순서.
- 참여자 결과 화면과 운영자 투표 화면이 같은 그래프 구성 요소를 쓴다. 운영자 화면에서는 기명 투표일 때 그래프 아래에 선택지별 이름 목록을 붙인다.

### 스키마 변경 (`schema.sql`)

- polls: 마감 시각 컬럼(비어 있을 수 있음), 기명 여부 컬럼(기본값 거짓 — 기존 투표는 익명) 추가.
- votes: 참여자 이름 컬럼(비어 있을 수 있음 — 익명 투표와 기존 표) 추가.
- 기존 데이터를 보존하는 방식(`ADD COLUMN IF NOT EXISTS`)으로 여러 번 적용해도 안전하게 한다.
- 새 투표의 기명 여부 기본값(기명)은 만들기 화면에서 정한다. DB 기본값은 기존 데이터 보존을 위해 익명이다.
- 배포 후 `npm run db:schema`로 로컬(`.env.local`)과 배포 DB(Neon `production` 브랜치)에 적용해야 한다.

### 화면

- 투표 만들기: 마감 시각 입력칸(24시간 뒤 미리 채움) + "마감 시각 없음" 체크박스, 기명 투표 체크박스(기본 켜짐) + "켜면 참여자 이름이 표에 남고, 운영자만 누가 무엇을 골랐는지 봅니다" 설명.
- 운영자 투표 화면: 기존 내용 + 마감 시각 표시, 진행 중이면 마감 시각 입력칸·저장·"마감 시각 없애기", 기명/익명 표시, 기명이면 선택지별 이름 목록.
- 참여자 투표 화면: 마감 시각·남은 시간, 기명/익명 안내, 가로 막대 그래프.
- 목록(참여자·운영자): 마감 시각·남은 시간, 24시간 이내 강조, 새 정렬 순서. 운영자 목록에는 기명/익명 표시.

## Testing Decisions

- 좋은 테스트는 모듈의 공개 인터페이스로 **외부에서 관찰되는 동작**만 검증한다. SQL 문장, 컬럼 이름, 함수 호출 순서 같은 구현 세부는 검증하지 않는다. 기대값은 독립적인 근거(손으로 계산한 예시, 스펙)에서 온다.
- **투표 모듈 (기존 경계, PGlite)**: 기존 테스트와 같은 방식으로 실제 Postgres(PGlite)에 `schema.sql`을 적용해 검증한다. 현재 시각은 테스트가 고정해 주입한다. 검증 대상:
  - 마감 시각: 마감 시각이 지나면 표 거부(마감된 투표), 지나기 1분 전에는 허용, 지나면 미참여자에게 결과 공개, 운영자 마감이 마감 시각보다 먼저여도 마감
  - 만들기: 과거·현재 마감 시각 거부, 마감 시각 없음 허용, 기명 여부 저장
  - 마감 시각 설정: 넣기·바꾸기·없애기, 과거 시각 거부, 마감된 투표 거부, 없는 투표 거부, 바꾼 뒤 마감 판단이 새 시각을 따름
  - 목록 정렬: 마감 시각 가까운 순 → 마감 시각 없는 진행 중 최신순 → 마감됨 최신순
  - 결과 1위: 단독 1위, 동점 모두 1위, 0표면 1위 없음
  - 기명 투표: 이름 없이 표 거부, 이름 규칙 위반 거부, 운영자 조회에 선택지별 이름이 던진 순서대로, 같은 이름 중복 허용, 참여자 조회에는 이름이 없음
  - 익명 투표: 이름을 넘겨도 운영자 조회에 이름 목록 없음
  - 기존 방식으로 만든(기명 여부를 정하지 않은) 투표는 익명
- **시각 표시 모듈 (새 경계, 순수 함수)**: 한국 시간 입력칸 값 ↔ 시각 왕복, 자정·날짜 경계, 24시간 뒤 기본값, "9월 30일 (화) 18:00 마감" 문구, 남은 시간 문구(분·시간·일 경계), 24시간 이내 판단(경계 포함). 테스트 실행 환경의 시간대와 무관하게 통과해야 한다.
- **참여자 이름 검증 (순수 함수)**: 빈 값·공백만·20자·21자·앞뒤 공백 제거.
- **운영자 인증 모듈**: 변경 없음. 기존 테스트 유지.
- **테스트하지 않는 것**: 화면 컴포넌트, 서버 액션(얇은 연결층), 쿠키 입출력 연결부, 이름 입력 화면 리다이렉트, 그래프 CSS.
- 선행 사례: 투표 모듈 테스트(PGlite, 테스트마다 데이터를 비우는 공용 테스트 DB 도우미)와 운영자 인증 모듈 테스트(시각 주입).

## Out of Scope

- 참여자 결과 화면에 이름 공개(공개 기명 투표)
- 이름으로 중복 투표 막기, 참여자 로그인·계정
- 만든 뒤 기명·익명 바꾸기
- 마감된 투표 다시 열기, 마감된 투표의 마감 시각 변경
- 예약 작업(cron)으로 마감 처리, 마감 알림(푸시·메일·카톡)
- 실시간 카운트다운(초 단위), 결과 실시간 자동 갱신
- 원그래프·세로 막대 등 다른 그래프 형태, 차트 라이브러리 도입
- 한국 외 시간대 지원
- 운영자 이름 목록 내보내기(CSV 등)
