# 동아리 투표

동아리에서 질문 하나에 선택지 중 하나를 골라 의견을 모으고 결과를 확인하기 위한 앱.

## Language

**투표 (Poll)**:
운영자가 만든, 질문 1개와 선택지 여러 개로 이루어진 묶음.
_Avoid_: 설문, 질문(묶음 전체를 가리킬 때), 투표(한 사람의 선택을 가리킬 때)

**선택지 (Option)**:
하나의 투표 안에 있는 보기 하나.
_Avoid_: 항목, 답변, 후보

**표 (Vote)**:
참여자 한 명이 한 투표에서 선택지 하나를 고른 기록.
_Avoid_: 투표(행위·기록을 가리킬 때), 응답

**운영자 (Admin)**:
비밀번호로 로그인해 투표를 만들고 삭제하는 사람.
_Avoid_: 관리자, 회장, 호스트

**참여자 (Voter)**:
투표에 표를 던지는 동아리원. 로그인하지 않으며, 브라우저 단위로 구분된다. 앱에 들어올 때 참여자 이름을 적는다.
_Avoid_: 사용자, 회원, 응답자

**참여자 이름 (Voter Name)**:
참여자가 앱에 들어올 때 직접 적는 이름. 화면에 표시되고 기명 투표의 표에 붙지만, 참여자를 식별하거나 중복을 막는 데는 쓰지 않는다.
_Avoid_: 닉네임, 아이디, 계정

**마감 (Close)**:
투표가 더 이상 표를 받지 않는 상태가 되는 것. 운영자가 직접 마감하거나 마감 시각이 지나면 마감된다. 마감된 투표의 결과는 남는다.
_Avoid_: 종료, 삭제(결과까지 사라지는 것과 구분)

**마감 시각 (Deadline)**:
투표가 자동으로 마감되는 시각. 투표마다 없을 수도 있고, 마감 전까지 운영자가 넣거나 바꾸거나 없앨 수 있다.
_Avoid_: 마감(시각 자체를 가리킬 때), 기한, 종료 시간

**기명 투표 (Named Poll)**:
표에 던진 시점의 참여자 이름이 함께 남는 투표. 누가 어떤 선택지를 골랐는지는 운영자만 본다. 만들 때 정하며 이후 바꿀 수 없다.
_Avoid_: 실명 투표, 공개 투표

**익명 투표 (Anonymous Poll)**:
표에 참여자 이름을 남기지 않는 투표.
_Avoid_: 비밀 투표, 무기명

**결과 (Result)**:
한 투표에서 선택지별로 받은 표의 집계.
_Avoid_: 통계, 현황
