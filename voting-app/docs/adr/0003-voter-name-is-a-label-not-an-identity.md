# 참여자 이름은 표에 붙는 꼬리표일 뿐, 식별 수단이 아니다

참여자는 앱에 들어올 때 이름을 적고, 기명 투표에서는 표를 던진 시점의 이름이 표에 남는다. 이 이름은 운영자가 "누가 무엇을 골랐는지" 보기 위한 꼬리표로만 쓰고, 중복 방지는 ADR-0001대로 브라우저 쿠키로 한다. 이름은 사칭이 쉬워 식별 수단으로 믿을 수 없고, 같은 이름으로 한 번만 투표하게 막으면 동명이인이 투표하지 못한다. 선택 내역은 운영자에게만 보이고 참여자 결과 화면은 집계만 보여, 공개 부담 없이 참여 독려에 쓸 수 있게 했다.

## Consequences

- 같은 이름이 한 투표에 여러 번 나올 수 있다(동명이인, 다른 기기). 운영자가 명단에서 판단한다.
- 참여자가 나중에 이름을 바꿔도 이미 던진 표의 이름은 바뀌지 않는다.
- 기명/익명은 투표를 만들 때 정하고 바꿀 수 없다. 익명이라고 믿고 던진 표에 나중에 이름이 드러나면 안 된다. 이 기능 이전에 만든 투표는 익명 투표다.
- 참여자 결과 화면에 이름을 노출하는 기능(공개 기명 투표)을 추가하려면 이 결정을 다시 열어야 한다.
