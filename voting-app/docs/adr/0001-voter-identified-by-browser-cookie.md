# 참여자는 로그인 없이 브라우저 쿠키로 구분한다

동아리 내부용 투표라 완벽한 중복 방지보다 참여 문턱을 낮추는 게 중요하다고 판단해, 참여자 로그인 없이 브라우저 쿠키에 담긴 무작위 식별자로 "한 투표에 한 표"를 보장한다. 시크릿 창·다른 기기·쿠키 삭제로 다시 투표할 수 있다는 한계는 알고 받아들인 것이다.

## Considered Options

- **중복 방지 없음**: 새로고침만으로 여러 표가 가능해 결과를 믿을 수 없다.
- **이름·학번 입력**: 사칭이 쉬워 쿠키보다 나을 게 없고 입력만 번거롭다.
- **참여자 로그인**: 가장 정확하지만 동아리원 계정 관리가 필요해 앱 규모에 비해 무겁다.

## Consequences

나중에 참여자 로그인으로 바꾸면 기존 표는 쿠키 식별자에만 묶여 있어 계정과 연결할 수 없다.
